# DB 보강 파일럿 (2026-11-11)

대규모 보강에 앞서 작은 규모로 넣고, 같은 LLM 출력(캐시) 기준으로 효과를 측정했습니다.

## 1. 식단: 브랜드·포장 제품 라벨 표 (14개)

- **파일:** `data/curated/curated_products.csv`
  - 컬럼: 제품명, 별칭, 1단위 g, 라벨 kcal·탄단지, 근거 URL, 신뢰도
- **로더:** `engines/food/curated_products.py`
  - 매칭 순서: 정확한 이름/별칭 → 기록된 이름 안에 포함된 가장 긴 별칭 (예: "편의점 바나나우유")
- **적용 위치:** 식단 보강 단계 맨 앞 (`_enrich_macros`)
- **값 출처:** 웹 검색으로 판매처·제조사 표시값을 우선 확인했습니다.
  - 칼로리 DB(FatSecret 등)는 보조로만 썼습니다.
  - 탄단지가 표시되지 않은 제품은 kcal만 라벨값이고, 탄단지는 `kcal_label_macros_estimated`로 표시했습니다.
  - 참치마요 삼각김밥은 제품 버전이 여러 개라 `low`로 표시했습니다.
- **대상 제품:** 신라면, 진라면, 불닭볶음면, 육개장 사발면(컵라면 일반), 햇반, 빅맥, 바나나맛우유, 포카리스웨트, 핫식스, 초코파이, 허니버터칩, 빼빼로, 메로나, 참치마요 삼각김밥

| 지표 (266건) | 이전 | 이후 |
|---|---|---|
| 총 칼로리 범위 내 | 79.7% | **83.1%** |
| 총 칼로리 범위 내 (test) | 78.8% | **81.0%** |
| 모든 단계 정답 | 168 | **179** (그중 6건은 채점 규칙 변경 효과) |
| 모든 단계 정답 (test) | 86 | **90** |

채점 규칙 변경: 제품 라벨 행으로 매칭된 항목도 정답 출처로 인정합니다. 같은 제품을 일반 "라면" 행보다 정확히 가리키기 때문입니다. kcal은 그대로 범위 검사를 받습니다. 규칙 변경과 무관한 지표는 총 칼로리이며, **+3.4%p** 올랐습니다.

## 2. 영양제: KB 성분 프로필 3개

- **추가 성분:** `ING_CALCIUM`, `ING_VITAMIN_C`, `ING_MELATONIN` (`data/documents/supplement_ingredient_profiles.json`)
  - 기존 형식을 그대로 따랐습니다. 특정 용량은 적지 않았고, 위험군에는 상담 안내를 붙였습니다.
  - 멜라토닌은 국내 전문의약품이라는 점을 명시했습니다.
- **별칭:** 멜라토닌, 탄산칼슘, 구연산칼슘
- **전후 비교 방법:** 보강 전에 질문 9건(`supplement_eval_kbpilot.jsonl`)을 먼저 작성하고, 같은 질문으로 보강 전후를 비교했습니다. 9건은 기존 KB 밖 질문 3건과 신규 6건입니다.

| 지표 | 보강 전 | 보강 후 |
|---|---|---|
| 파일럿 9건 통과 | 0/9 (5건이 "확인 불가" 템플릿) | **9/9** |
| 영양제 전체 109건 | 102 (test 40) | **103 (test 41)** |
| 프롬프트가 바뀐 기존 32건 | | 회귀 없음 |

주의:
- **KB 정확성은 측정 대상이 아닙니다.** KB 내용과 파일럿 라벨을 같은 작성자가 만들었습니다. 따라서 이 결과는 "KB에 있으면 파이프라인이 그 사실을 답변에 반영하는가"를 보여 줄 뿐입니다.
- **KB 내용 검수 필요:** 대규모로 넣기 전에 약사 등 전문가가 검수해야 합니다.

## 3. 결론과 대규모 보강 제안

- **효과:** 두 보강 모두 효과가 확인됐습니다. 코드 변경은 로더와 별칭뿐이고, 개선은 데이터 추가만으로 나왔습니다.
- **식단 다음 단계:**
  - 자주 기록되는 제품부터 100~300개로 확대합니다.
  - 값은 식약처 "식품영양성분 데이터베이스(가공식품)"를 일괄로 받아 쓰는 방식을 권장합니다. 제품명, 1회 제공량, 영양성분이 공식값으로 들어 있어 수작업 검색보다 정확합니다.
  - 1인분 무게 표(`SERVING_GRAMS_BY_SUFFIX`)도 같은 출처의 1회 제공량으로 CSV화합니다.
- **영양제 다음 단계:**
  - 질문 빈도가 높은 성분 10~15개를 추가합니다 (비타민B군, 루테인, 콜라겐, 코엔자임Q10, 아르기닌, BCAA/EAA, 글루타민, 비오틴, 엽산, 셀레늄 등).
  - 상호작용 규칙도 함께 추가합니다.
  - 출처는 식약처 건강기능식품 기능성 원료 고시를 우선하고, 전문가 검수를 거칩니다.
- **회귀 확인:** 보강할 때마다 `regression_gate.py --profile full`로 회귀를 확인합니다. 새 성분이나 제품 질문은 보강 전에 평가셋에 먼저 추가해서 전후를 비교합니다.
