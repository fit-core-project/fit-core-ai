## 식단 변경

- 가공식품 "하나/개": 최소 포장(50ml 샘플) 대신 1회 섭취분 이상인 최소 포장 (아침햇살 50→180ml, 포스틱 30→84g). 2개 이상이면 낱개(칙촉 3개).
- 음료 제품은 끝 단어로 낱개 중량을 쓰지 않음 (덴마크 요구르트 딸기 = 딸기 15g 버그).
- 캔 크기 정보가 없는 음료 캔 = 250ml (맥콜).
- 메뉴명 변형("콤비네이션피자", "고구마피자", "물냉면")은 일반 음식으로 처리 → 냉동피자 제품 오매칭 제거.
- 브랜드 접두어 생략 매칭 (왕뚜껑 → 팔도 왕뚜껑), 포장식품만.
- 고깃집 부위 별칭: 목살, 차돌(박이), 막창, LA갈비 → 구운 DB 행.
- 위스키/양주 잔 40ml, 하이볼 350ml, 오메가3·멀티비타민 알 단위(~1g), "오메가3"의 3을 수량으로 읽지 않음.
- DB에 없는 음료 라벨값: 파워에이드, 게토레이, 몬스터(울트라), 레드불.
- 원재료 품종 재정렬 (찰옥수수 → 말린것 대신 삶은것), 샤인머스캣/단호박 별칭.
- 곱빼기·대자 등 크기 단어가 단위로 온 경우 1인분 + 크기 배수; 영어 단위(slices 등).
- 버거 낱개 190g (싸이버거 230g 별도).

## 영양제 변경

- 큐레이션 규칙이 없는 조합(아연+마그네슘, 당뇨약+프로틴)에 "병용 자료 없음" 안내. 프로필이 상대 성분을 언급하면 제외.
- KB에 없는 흔한 성분명(가르시니아, 홍삼, 프로폴리스 등) 언급 시 "자료 없음" 안내.
- 별칭: 셀렌, 아세트아미노펜, blood thinner/혈액희석제, 투석/신부전, 소주·맥주·와인, 마그내슘.
- 성분 없이 약/상황만 물으면("혈압약 먹는 사람은 뭘 조심", "임신 초기 영양제") 해당 규칙 우선 검색.
- 목적 추천 템플릿에서 "corpus" 영어 제거.
- 평가 하네스: 정직성/포함어 매칭 띄어쓰기 무시, "자료에 없", "자료에 포함되어 있지 않" 마커, "복용하지 않"≈"복용하지 마".

## 2026-11-16 blind holdout v2 (튜닝에 쓰지 않은 검증)

구성: 서브에이전트가 엔진/큐레이션/캐시를 보지 않고 원본 DB·KB만으로 작성 → 별도 감사 에이전트(식단 5, 영양제 4)가 라벨만 검토 → 과도하게 엄격한 라벨 완화(영양제 포함어 33건, 식단 kcal 범위 20건), 판단이 갈리는 영양제 3건은 `supplement_eval_holdout_v2_ambiguous.jsonl`로 분리. 그 뒤 live 1회 측정, v2 결과로 코드 수정 없음.

|---|---|

식단 실패(첫 실패 단계): 매칭 25, 분량 25, 파싱 9, kcal 9.
- 처음 보는 요리는 1인분 무게를 몰라 100g(또는 DB 기준량)으로 계산: 잡채밥 315, 팟타이 146, 깐풍기 164, 티라미수 62.
- 낱개 무게를 모르는 간식은 반대로 과대: 약과 3개 1197, 송편 5개 1000, 꿀떡 7개 1596, 붕어빵 3마리 840.
- DB 미매칭: 항정살, 오리로스, 소대창, 쭈꾸미볶음, 소고기뭇국, 청하, 고량주, 영어 입력(pad thai, croquettes).
- 인덱스에 없는/못 찾는 제품: 데자와, 웰치스, 불가리스, 맥치킨, bhc·BBQ 메뉴, 대선.
- 파싱: "반은 남김", "3개 사서 하나는 동생 줌", "굶음", 부정문 뒤 실제 먹은 것 누락.

영양제 실패(첫 실패 단계): 질의 이해(S1) 12, 답변(S3) 10. 답변 단계 실패는 총 11건.
- S1: 구어체 맥락(임테기 두 줄=임신, 모유 먹이는데=수유, 면역억제제), 별칭(유비퀴놀, Withania somnifera, 아스코르브산, 오메가쓰리, magnesiun). 이 중 다수는 답변 자체는 적절.
- S3: KB에 없는 효능/대상(주름, 미백, 코로나, 청소년, 영아) 질문에 "자료 없음" 안내 누락 8건, 엉뚱한 템플릿 답변 2건(NAC 숙취, 항암 중 비타민C 주사), 상담 권고 누락 1건(세인트존스워트+피임약), 용량 수치 언급 1건.

결론: 기존 세트 수치(식단 93%, 영양제 97%)는 튜닝 세트에 맞춰진 값이고, 처음 보는 입력에서는 식단 약 50%, 영양제 약 70% 수준. 개별 음식/표현 추가보다 일반 규칙(모르는 요리의 1인분 추정, 낱개 무게 추정, KB 미포함 판단)을 고쳐야 함.
