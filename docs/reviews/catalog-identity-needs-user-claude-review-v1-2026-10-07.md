# 연결 후보 "사용자 판단 필요" 13쌍 검토 (Claude, 2026-10-07)

사용자 위임: "사용자 판단 필요 13쌍은 일단 당신이 확인". 근거: `catalog-identity-codex-review-v1-2026-10-07.json`의 원천 메타데이터, 코어 SQLite `exercise_muscle_taxonomy_v2`(read-only 조회).

## 핵심 발견
- 13쌍 대부분은 **운동 자체는 같은 운동**이다. 충돌은 카탈로그의 파생 주동근·동작 유형·장비 값에서 난다.
- 런타임은 원값이 아니라 보정 분류(`canonical_primary_muscle`)를 쓴다. 보정으로 해결된 것: 슈러그→trapezius, 해머 컬→biceps, 힙 쓰러스트·프로그 펌프→gluteal.
- **보정되지 않은 오분류가 confidence high로 남아 있음**: 전완/악력 운동(리스트 롤러 004721, 그리퍼 004723, 플레이트 핀치 004722)이 `upper-back`, 클램셸 004710이 `adductor`(실제는 외전·외회전). `detail_subpart='전완/악력'` 11행 전부 upper-back, `고관절 안정화/내전외전` 7행이 adductor. 숫자 ID 연결과 무관하게 **네이티브 V24ROW 추천에도 영향 가능**(등 타깃 요청에 전완 운동이 후보가 될 수 있음) — 별도 확인 필요.
